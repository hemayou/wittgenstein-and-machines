# 维特根斯坦与机器

从 1939 年剑桥那间教室里的一场争吵出发，持续追问一组问题：意义依赖什么、规范性从哪里来、机器能不能进入我们的语言游戏，以及在一个语料正在被机器自产的时代，一手的观察与实践还值多少钱。

这不是一个论文项目，是一个**滚动的探索档案**。每一轮讨论的判断、争议、引证和待办都往里沉淀，允许自我推翻——被推翻的判断不删除，移到台账的「已翻案」区并记下为什么。

## 工作规矩

1. **回到原文。** 转述不算数。凡引用维特根斯坦，给节号（PI §201 这种）；凡引用论文，给作者年份，并在 `引证库.md` 留一条。
2. **未核验的标出来。** 模型给的引证默认不可信，包括我自己给的。`[待核验]` 是这个项目里最重要的标记。
3. **判断要有反方。** 每条进入台账的判断，必须同时记下最强的反驳是什么。反驳记不出来，说明这条判断还没想清楚。
4. **区分三种东西**：文本说了什么（诠释）、事情是不是这样（论证）、这对我意味着什么（应用）。混在一起写就是这类讨论最常见的滑坡。
