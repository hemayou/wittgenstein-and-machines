# 线 03｜判据与证据

问题清单见 `../../AGENDA.md` 线 03。

## 核心区分

- **判据（criteria）是构成性的**：它参与规定这个词的意义。满足判据不是「支持一个独立事实」，而是「这个词在这里有得用」。
- **证据（evidence / symptoms）是归纳性的**：它支持一个本来就独立成立的事实主张。

把 criteria 读成 evidence，整个后期维特根斯坦就被压平成了行为主义——这正是「图灵测试是维特根斯坦式的」这个流行说法的来路。清算这个误读是这条线的第一件事。

## 最难的那一问

**为什么这么多人会觉得模型比身边大多数人更理解自己？**

这不能用「ELIZA 效应」四个字打发。要认真处理的可能性至少有：无限耐心与零社会成本、完全的注意力在场、不带自身议程、以及后训练直接优化了「让人觉得被理解」这个目标。注意最后一条与线 01 的连接——**这恰恰是评价性规范被大规模施加的结果**。

如果这个解释成立，那么「活人感」就不是被涌现出来的，是被训练出来的；而人们感受到的理解，是真实的感受，指向的却是一个被优化过的表面。维特根斯坦会怎么处理这种情况，是这条线最值得写的一段。
